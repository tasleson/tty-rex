# Files from Ptyxis

tty-rex shares its settings, palettes, icons and stylesheet with
[Ptyxis](https://gitlab.gnome.org/chergert/ptyxis), so these files are
copied unchanged from the `src/` directory of the Ptyxis tree
(commit 352807884e20aea8d5f6601ded72d12bede50ee1):

- `org.gnome.Ptyxis.gschema.xml.in`
- `style.css`
- `palettes/`
- `icons/`

They are GPL-3.0-or-later like the rest of tty-rex. To pick up upstream
changes, copy the same paths from a newer Ptyxis checkout and note its
commit here.
